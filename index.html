What is "Calibrated Time"?

Smart cubes log turns using internal hardware crystal timestamps. Because Bluetooth wireless packet transmissions encounter latency and jitter (10-50ms), we perform a Linear Regression Calibration fitting hardware timestamps with browser monotonic time. This removes transmission lag and reconstructs millisecond-accurate physical turn timing.

Help & Speedcubing Guide

How it Works:

  1. Connect Cube: Click "Connect Cube" and select your GAN/MonsterGo smart cube in the Bluetooth dialog.
  2. Scramble: Follow the WCA scramble sequence. The active move is highlighted in real time as you turn the physical cube.
  3. Smart Scramble Correction: If you make a wrong move, the app immediately computes the shortest corrective moves so you don't need to restart!
  4. Signal on Finished Scramble: When the cube reaches the target scrambled state, a visual green pulse and an audio chime will play.
  5. Auto Start: The timer starts the instant you make your first turn on the cube.
  6. Auto Stop: The timer automatically stops the instant the cube is solved.
  7. Recalibrate / Set Solved: Click "Set Solved" (or press 'R') if your cube state ever needs manual synchronization.

Frequently Asked Questions:

1. How do you count movements? Does X2 count as 1 or 2? • In OBTM / HTM (Outer Block / Half Turn Metric, the standard WCA competition default), any single face rotation of 90° or 180° (e.g. U, U2, R2) counts as 1 move.
• In QTM (Quarter Turn Metric), 180° double turns (U2, R2) count as 2 moves, while 90° turns count as 1 move.
• You can toggle your preferred metric in Settings!
2. What is Calibrate Time and why is it needed? Bluetooth wireless packets suffer from transmission jitter, OS queue delays, and GATT connection intervals (10-50ms variance). The smart cube's internal microcontroller hardware clock records the exact physical moment each layer turned. Our Linear Regression Calibration aligns hardware timestamps with the timer to eliminate Bluetooth radio lag, giving true physical solve time and instant TPS.

Keyboard Shortcuts:

  • Space: Manual Start / Stop (if not using Bluetooth turns)
  • N: Generate New Scramble
  • R: Recalibrate / Set Solved
  • Esc: Reset Timer / Close Modals
